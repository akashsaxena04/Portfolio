This is my personal **developer portfolio website** built to showcase my projects, skills, certifications, and achievements in web development.

The portfolio highlights my work, technical abilities, and provides an easy way for recruiters and collaborators to connect with me.

---

## 🚀 Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Vite
* Responsive Design

---

## ✨ Features

* Responsive modern UI
* Interactive animations and effects
* Projects showcase section
* Skills and certifications display
* Resume download option
* Contact section
